## 신발 관리

- 브랜드·모델명·구매 날짜는 필수입니다.
- 사이즈는 mm 단위 선택 메뉴, 구매 날짜는 날짜 선택 위젯을 사용합니다.
- 사이즈·색상·신발 상태·누적 거리·러닝 횟수·메모는 선택입니다.
- 입력하는 누적 거리와 횟수는 **이 앱에 등록하기 전의 기록**입니다. 이후 연결한 러닝 기록이 합산됩니다.
- 추가·편집·삭제를 지원합니다. 신발 삭제 후에도 러닝 기록과 당시 신발 이름은 유지됩니다.

## 러닝 기록

- 시작 날짜·시간, 러닝 시간, 거리만 필수입니다.
- 평균 페이스, 평균 심박수, 칼로리, 신발, 평균 속도, 러닝 후 평가, 기온, 메모는 선택입니다.
- 평가는 `great`, `good`, `bad`, `easy`, `hard` 중 선택합니다.
- 페이스는 `6:09` 또는 `6.15`처럼 입력합니다. 미입력 시 표시 페이스는 시간÷거리로 계산합니다.
- 편집·삭제 시 홈 통계와 신발 누적 기록도 다시 계산됩니다.

## 홈과 AI 화면

- 홈은 월요일~일요일 기준 이번 주 총 거리, 총 러닝 시간, 평균 페이스와 최근 기록 3개를 표시합니다.
- 주간 평균 페이스는 각 기록 페이스의 단순 평균이 아니라 **전체 시간÷전체 거리**입니다.
- AI 추천 내용은 별도 화면에만 표시합니다. 현재 백엔드 AI 서비스가 미구현 상태이므로 화면에 예시임을 명시했습니다.
- 현재 로그인·서버 동기화는 연결하지 않았으며, 신발과 러닝 기록은 이 기기에 저장됩니다.

## 디자인과 검증

- Figma의 `Home`, `shoes_plus`, `Running_plus`를 수정했습니다. 기존 화면 사본은 숨김 보관했습니다.
- 긴 Figma 폼은 전체 항목을 볼 수 있도록 프레임을 늘렸고, 앱에서는 스크롤과 고정 저장 버튼을 사용합니다.
- 원본 프로필·설정·하단 메뉴 자산과 Inter 글꼴을 로컬로 포함했습니다.
- Figma Starter 플랜 호출 한도에 도달하여 추가 도구 조회·수정은 제한됩니다. 홈의 예시 평균 페이스는 Figma에는 `5:58 /km`로 남아 있으나 앱은 올바른 계산값인 `5:59 /km`를 표시합니다.
- APK 빌드, 단위 테스트 18개, Android 14 에뮬레이터 테스트 4개와 Lint 검사를 통과했습니다. 기존 라이브러리 업데이트·저장소 권한 등의 Lint 경고는 남아 있습니다.

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
.\gradlew.bat connectedDebugAndroidTest --max-workers=2
```
